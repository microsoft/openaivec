# 大量の表・文章・ファイルを、まとめて処理する

「この表の文章、全部分類したい」「このフォルダの資料から必要な情報を
一気に取り出したい」。そんな時に、チャットで目的を伝え、少量の結果を
確認してからまとめて処理するためのスキルです。

**コードを書く必要も、処理設定を調整する必要もありません。**
アシスタントが準備と高速処理を担当します。利用者が決めるのは
「何をしたいか」「何を対象にするか」「この結果でよいか」です。

## 得意な仕事

| 対象 | できること |
| --- | --- |
| 大量のアンケート・口コミ | 文章を話題・感情・要確認事項などで分類する |
| 問い合わせや商談メモの表 | 要点、依頼内容、次の行動などを列に整理する |
| 請求書・見積書・報告書のフォルダ | 書かれている事実を確認用の一覧にする |
| 商品説明や多言語の文章 | 分類・表記統一・翻訳をまとめて行う |
| 資料集と質問の一覧 | 意味が近い資料をそれぞれの質問に対応づける |
| 一部の分類が空欄の表 | 正解のある行で精度を確かめてから空欄を補う |

対応している表形式や文書は、アシスタントが先に確認します。
単純な合計・並べ替え・形式変換や、Excelの見た目の編集には使いません。
法務・医療・採用・与信・支払いなどの重要な判断は人が行います。

## 1. チャットでインストールを頼む

GitHub Copilot、Claude Code、Codex、Cursorなど、スキルに対応した
アシスタントで作業用のプロジェクトを開き、次をそのまま貼ってください。
自分でコマンドを実行したり、保存場所を調べたりする必要はありません。

```text
Microsoft公式の microsoft/openaivec から openaivec-skill を、
このプロジェクトだけで使えるようにインストールしてください。

公式GitHubのリリースから、openaivec-skill-vX.Y.Z というタグの
最新の安定版スキルを選び、その正確なタグに固定してください。
ライブラリ本体のリリースや開発中の内容は選ばないでください。
インストール前に、追加するファイルと影響する範囲を簡潔に説明し、
既存のスキルを置き換える場合は止めて、私の承認を求めてください。

承認後は、このアシスタントに対応した方法でインストールを実行し、
公式の入手元、バージョン、このプロジェクトだけで使う設定であることを
確認してください。新しいチャットが必要なら教えてください。
業務データを開くこと、処理用ソフトの追加、認証設定、AIへの送信は、
このインストールでは行わないでください。
私にコマンド実行を求めず、ここで導入できない場合は管理者向けの
依頼文を作ってください。
```

追加される内容の説明を読み、問題なければ承認します。
アシスタントが導入を確認したら、必要に応じて新しいチャットを開きます。

会社のAI接続や追加ソフトが必要な場合は、後でアシスタントが説明します。
APIキーやパスワードをチャットに貼る必要はありません。
環境の準備が必要な時だけ、影響を確認して承認してください。

## 2. ふつうの言葉で仕事を頼む

**スキル名を毎回指定する必要はありません。**
大量のテキスト入りの表や文書群を扱う依頼から、アシスタントが活用します。
許可したデータ確認で向いている文章が見つかった場合にも、使い方を提案します。
見つけただけで勝手に有料処理を始めることはありません。

### 表の文章を分類したい

```text
surveys/customer_feedback.xlsx のコメントを、全部まとめて
話題と感情で分類してください。元の回答番号と行は残し、
元ファイルは変更しないでください。
便利な結果の列を提案し、少量で試してから、選択肢で案内してください。
データの送信と、新しい結果ファイルの作成は承認を取ってください。
```

### フォルダの資料を一覧にしたい

```text
incoming/quotes/ の見積書をまとめて確認したいです。
取引先、見積番号、金額、通貨、納期を一覧にして、
読み取れない情報は推測せず要確認にしてください。
まず数件の結果を見せてください。元のファイルは変更しないでください。
```

### やりたいことがまだ曖昧

```text
この表には大量の自由記述があります。業務で使いやすくしたいので、
向いている分類・抽出・要約の方法を選択肢で提案してください。
まずは確認だけで、勝手に送信や保存はしないでください。
```

## 3. 少量の結果を確認して、一括実行を承認する

| 案内される段階 | 利用者がすること |
| --- | --- |
| 目的 | 分類・抽出・要約など、必要な結果を選ぶ |
| 対象 | 未指定なら、表・列・シート・フォルダを選ぶ |
| 試行 | 数件の結果を見て、問題なければ承認する |
| 一括実行 | 対象件数、送信先、保存先を確認して実行を承認する |

すでに伝えたことは、もう一度選ぶ必要はありません。
結果が違う場合は「分類を変えて」「この項目も欲しい」と伝えてください。
試行の承認と、全件実行の承認は別です。

同じ内容の文章はまとめて処理し、その結果をすべての元の行へ戻します。
試行で確認した結果も再利用します。**重複した行を削除するわけではありません。**
分類と要約などの関連する項目も、できるだけ一度に取り出します。

実際の速度と料金は、文章の長さ、文書の種類、利用するサービスなどに
左右されます。アシスタントは送信する情報と料金見積りの限界を説明し、
長い処理では進捗を知らせます。一定の速度や料金を保証するものではありません。

## 完了したら確認すること

アシスタントは、結果の場所、入力と出力の件数、要確認の件数、
元データを変更していないことを簡潔に伝えます。
新しい出力は作成後にも読み直して確認します。
空欄・読み取り不能・不明な内容は、勝手に補って成功扱いにしません。

問題が起きたら、影響と次の選択肢を説明して処理を止めます。
接続先の変更、元ファイルの上書き、中間結果の保存を無断で行うことはありません。
必要な場合だけ、一時保存や管理者への依頼について相談します。
